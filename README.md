## 單機預覽模式

`app.js` 開頭的 `SUPABASE_URL`、`SUPABASE_ANON_KEY` 目前留空，網站會：

- 不需登入，直接進入
- 筆記、照片、勾選都只存在這台裝置（照片暫存為 Base64）
- 標頭顯示「單機預覽：尚未連接家人同步」

接上 Supabase 後，這台裝置上的照片會自動搬到雲端。

## 接上新的 Supabase 專案

1. 到 supabase.com 建立新專案。
2. **SQL Editor → New query**，貼上 `SUPABASE_SETUP.sql` 全部內容並按 **Run**（建立 `hokkaido_sync` 資料表與 `trip-media` 圖片空間）。
3. **Authentication → Users → Add user**，為每位家人建立 Email／Password，勾選 **Auto Confirm User**。
4. **Project Settings → API**，複製 Project URL 與 `anon public` key，填進 `app.js` 第 180 行附近的兩個常數。
5. 重新部署後，網站會出現登入畫面。
